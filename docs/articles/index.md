## Porting contract

Each page retains the frozen vignette topic, methodological scope, and interpretation boundary. Python examples use the native `gp3sequencespy` API and standard Python scientific objects; R-only backend objects are represented by the documented semantic adapters rather than emulated S3/S4 objects.
