# Security Policy

## Supported versions

`gp3sequencespy` is currently alpha software. Security and integrity fixes are
applied to the current `main` development line and the most recent published
release, when one exists.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Prefer GitHub's
private vulnerability-reporting / security-advisory mechanism for this
repository when available. If private reporting is unavailable, contact the
maintainer through the institutional contact information associated with the
repository and disclose only the minimum information needed to establish a
private channel.

Include the affected version or commit, environment, reproduction steps, and
impact. Non-sensitive correctness bugs should use the normal issue tracker.

## Scientific integrity issues

Incorrect statistical results, silent data corruption, reproducibility failures,
or violations of declared parity contracts should be reported even when they are
not conventional software-security vulnerabilities.
