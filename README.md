# gp3sequencespy

`gp3sequencespy` is the Python implementation of **gp3sequences 0.3.0**, providing transparent, reproducible, and auditable analysis of ordered categorical sequences and scanpaths.

The frozen R 0.3.0 tarball is the behavioral reference. The Python project is being implemented parity-first: native semantics first, optional ecosystem adapters second.

## Current development status

The package is in alpha development. Do not interpret structural sequence outputs as independent evidence of emotion, cognition, comprehension, personality, intention, deception, diagnosis, or causality.
